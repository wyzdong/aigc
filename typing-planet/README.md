# 打字星球 · 小小键盘探险家

适合儿童的英文打字练习静态网页，包含字母、单词、句子三条路线，每条路线 3 组练习，以及虚拟键盘提示、准确率与速度统计、星星奖励、成就和最近 10 次练习记录。

## 运行

直接在现代浏览器中打开 `dist/index.html`，或在本目录运行 `python3 -m http.server 8000 --directory dist` 后访问 `http://localhost:8000`。不需要安装依赖或构建。

## 文件

- `dist/index.html`：页面结构与中文内容。
- `dist/style.css`：样式和响应式布局。
- `dist/app.js`：练习逻辑与本地进度存储。

这是原始可编辑的 HTML、CSS 和 JavaScript，`dist/` 是原项目的目录名，不是需要另外寻找源文件的编译产物。没有服务端、账号系统、云端同步或第三方网络请求。

## 数据与隐私

进度使用当前浏览器的 `localStorage`，键名为 `typingPlanet`。清除浏览器站点数据会清除该设备上的记录；不同浏览器、设备和来源之间不自动同步。本次导出只包含程序代码，没有导出任何实际练习记录、儿童信息、数据库、账号、凭据、环境变量或会话文件。
